# 单张照片转动态视频

用一张风景照片或插画做出分层动效。固定背景保留构图，云层在星空前方随风移动，云离开后露出补齐的背景。[五种场景做法](references/scenes.md)涵盖星空草地、云拱台阶、湖面帆船、粉云海面和暮色信号灯云景。包含草浪、水面倒影和尾波的制作要点。

## 使用

- 用 Codex 时，把仓库目录作为一个技能安装，或让 Codex 读取 [SKILL.md](SKILL.md) 并处理你的照片。
- 独立渲染时，先准备干净底图和对齐到画布的透明 PNG，再按照[渲染指南](references/render.md)填写场景 JSON。运行 `python scripts/animate.py scene.json output.mp4`。
- 指南附有循环 GIF 和 iPhone 实况照片转换用 MP4 的导出命令。实况照片需在支持的工具中转换并存入相册。

示例指令：把这张星空照片做成 5 秒短片。让云自然向右飘，遮住身后的星点，移开后露出干净的星空。

渲染脚本负责已准备图层的合成和写出。抠图、补齐背景和设计复杂局部动作需要根据原图完成。
